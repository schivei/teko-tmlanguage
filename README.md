# teko-tmlanguage

The TextMate grammar for the [Teko programming language](https://github.com/schivei/teko-lang) (`source.teko`, files `.tks` / `.tkt`).

Consumed by [github-linguist](https://github.com/github-linguist/linguist) (via `vendor/grammars`) and reusable by any TextMate-compatible editor (VS Code, Sublime Text, JetBrains TextMate bundles).
